## 1. 지금 있는 것

로그인하고 동의한 계정이 `/forecast` 맨 위 칸에 한국어로 물으면, 지금 열린 예측 질문 중 맞는 것을 골라
현재 확률·하루 참여 규모·수집 시각과 숫자 없는 해설로 답한다. 맞는 질문이 없으면 없다고 하고 가까운 질문을
두 개까지 "가까운 질문"으로 보인다.

| 단계 | 자리 |
|---|---|
| 1차 검색(LLM 없음, 공개 검색과 같다) | `polymarket/relevance.py` 용어집·중앙은행 구분·기간 가중, `annotate.refresh_labels` 선택지 이름 색인, `repository.candidates` |
| 답변 호출(질문당 1회, 반려 시 1회 교정) | `llm/polymarket_answer.py`, `prompts/polymarket_answer_ko.txt` |
| 서버 조립·상한·캐시·질의 로그 | `polymarket/ask.py`, `POST /api/forecast/ask` |

방식을 고른 근거(문서 RAG·OKF·text-to-SQL을 쓰지 않은 이유)는 이 파일의 첫 판(git 이력)에 있다. 요지는 하나다 —
자료가 4시간마다 바뀌는 확률 표라 숫자를 청크나 번들에 구우면 낡고, 모델이 숫자를 옮기면 남의 숫자를 붙인다.

## 2. 측정 (2026-11-04, 운영 수집분)

`python -m services.web.tests.polymarket_ask_probe`가 1차 검색의 상위 5·30 안 정답을 잰다. 판정자 1인이 고른
원문 제목 정규식이 정답이다.

| 묶음 | 고치기 전(글자열 검색 + 주석) | 고친 뒤 |
|---|---|---|
| 맞춘 20문항(용어집을 이 문항으로 고쳤다 — 낙관적) | 상위 5 13/17 · 상위 30 15/17 | 상위 5 18/18 · 상위 30 18/18 |
| 따로 둔 10문항 | — | 상위 5 9/9(1문항은 정답 질문의 확률을 읽지 못해 후보에서 빠짐) |
| 공개 검색 지연(30문항, `events()`) | p50 230ms · p90 482ms | p50 270ms · p90 380~460ms |

배포 뒤 실제 호출(2026-11-04 20:4x, 6문항): 후보가 있는 4문항은 1.3~2.2초·13~49 Neurons로 답했고, 직접 답이 모두
맞았다(연준 12월 결정·추가 인상·최대 기업·USD/KRW). "코스피 3000"·"삼성전자 사도 돼?"는 후보가 없어 모델을 부르지
않고 "없음"으로 답했다. 고친 것: 열리지 않은 자리채움 칸("Company H" 50%)이 선택지를 차지하던 것, 질문의 기준 숫자
("1500원")에 맞는 칸이 안 보이던 것, 직접 답 하나에 가까운 질문 넷이 붙던 것(이제 둘까지). 21:10 재확인에서 모델이
물은 칸을 사다리 전체(휴전 날짜 11칸·금값 7칸)로 찍고 "인하" 질문에 인상 칸을 찍어, 물은 칸을 서버가 먼저 정하게 하고
(질문 낱말·기준 숫자, 두 칸까지) 직접 답을 다섯에서 셋으로 줄였다.
21:25 재확인에서 휴전 사다리의 높은 등급("11월 7일까지 이어진다")을 해설이 "그 사이 끝난다"로 거꾸로 읽어,
여러 질문 묶음을 읽는 법을 프롬프트에 적었다. "15만 달러"·"연말"도 선택지(↑ 150,000·by December 31, 2026)에 닿게 했다.

"원달러 환율 1500원"은 처음 측정에서 0건이라 "없음"으로 봤으나 *Will USD/KRW hit __ in 2026?*이 열려 있었다.
용어집으로 찾게 되어 정답 문항으로 옮겼다.

## 3. 결정한 것

1. 공개 범위는 **로그인 계정만**(계정 하루 10회·서버 하루 3,000회·동시 2). 질문 원문이 Cloudflare로 가므로
   개인 리서치와 같은 동의를 받는다. `/privacy`에 적었다.
2. 질의 로그는 계정 식별값 없이 질문문·고른 질문·비용·지연만 30일.
3. 재정렬 호출을 따로 두지 않는다. 답변 호출이 후보 30 중에서 고르는 것이 재정렬이다
   (`polymarket-nl-search.md`의 재정렬 절은 지웠다).
4. 과거 비교는 하지 않는다("지금만 본다", 2026-09-01). "지난주 대비"에는 기록이 없다고 답한다.

## 4. 남은 것

1. **첫 주 실측** — 질의 로그로 문항당 Neurons(첫 실측 13~49)·지연(p50/p95)·"없음" 비율·답에 낸 질문 수를 보고
   상한과 이 문서를 고친다. 답변 품질은 질의 로그의 새 질문 20개를 사람이 판정한다(관련 없는 질문을 낸 비율
   10% 이하, 없어야 할 때 없다고 한 비율 90% 이상).
2. **주석 오배정** — 운영 색인에 *Ventuals FDV above ___ one day after launch?*가 연준 금리 요약·키워드로 달려 있다
   (주석 배치에서 행이 어긋난 것으로 보인다). 프롬프트가 "요약이 원문과 어긋나면 원문을 따른다"고 막지만, 공개
   검색에는 그대로 뜬다. 주석 one-shot에 원문 제목과 요약이 서로 닿는지 보는 검사를 둘지 정한다.
3. **공개 "많이 묻는 질문"(B')** — 질의 로그 상위 질문의 고른 질문 ID·해설만 미리 만들어 두고 숫자는 요청 때
   서버가 채운다. 해설은 고른 질문의 등급이 바뀔 때만 다시 쓴다(상한 하루 10문항 × 6주기). 로그가 2주 쌓인 뒤
   연다.
4. **답 평가 버튼** — 질의 로그에 좋아요·아니요를 남길지. 지금은 없다.
5. **판정이 나쁠 때만**: 주제 허브(세부 주제별 질문 묶음, 숫자 없음), 비스포츠 질문 임베딩 혼합 검색
   (`@cf/baai/bge-m3`, 1,384건 × 1024 × 4B ≈ 5.7MB).
